# PKKMB Universitas Narotama 2026**Tema:** CineAction — Mahakarya Garda Depan, Mengukir Dampak untuk NegeriAplikasi manajemen dan sistem kepanitiaan untuk Program Kehidupan Kampus Mahasiswa Baru (PKKMB) Universitas Narotama 2026. Backend awal dikembangkan dari proyek Absensi App.## Fitur Utama* **Landing Page & Informasi:** Portal informasi publik kegiatan.* **Autentikasi Aman:** Login berjenjang yang dilindungi Sanctum, proteksi IDOR, dan rate limiter.* **Dashboard Spesifik Peran:** Pemisahan antarmuka eksklusif bagi Peserta, Admin, dan Superadmin.* **Presensi Cerdas (QR Code):** Validasi kehadiran real-time menggunakan sistem enkripsi QR yang aman.* **Manajemen Akademik:** Kelompok, Tugas, Berita, Pelanggaran, dan Hasil Pengumpulan.* **Distribusi & Ekspor Data:** Pengelolaan rekapitulasi nilai dan presensi komprehensif.## Tech Stack* **Laravel 10*** **PHP 8.3*** **Livewire 2*** **Tailwind CSS 3*** **Laravel Mix 6*** **MySQL**## Persyaratan Lingkungan* PHP >= 8.3* Composer 2.x* Node.js & npm* MySQL## Cara Instalasi1. Persiapkan kode sumber pada lingkungan lokal.2. Instal ekstensi backend:   ```bash   composer install   ```3. Instal ekstensi frontend:   ```bash   npm install   ```4. Salin file template lingkungan:   ```bash   cp .env.example .env   ```5. Buat Application Key baru:   ```bash   php artisan key:generate   ```6. Atur koneksi database:   Buka file `.env` yang baru dibuat dan isi kredensial MySQL secara lokal:   ```env   DB_CONNECTION=mysql   DB_HOST=127.0.0.1   DB_PORT=3306   DB_DATABASE=nama_database_lokal   DB_USERNAME=root   DB_PASSWORD=secret   ```7. Konstruksi Tabel & Data Awal (*Opsional*):   ```bash   php artisan migrate --seed   ```8. Kompilasi Aset Frontend (CineAction CSS/JS):   ```bash   npm run dev   ```9. Jalankan Server:   ```bash   php artisan serve   ```### ⚠️ PERINGATAN KEAMANAN TERAKHIR* **JANGAN PERNAH** mengunggah file `.env` ke dalam _repository_ publik.* **JANGAN MENYIMPAN** password akun asli, NIM, atau rahasia apapun (seperti `APP_KEY` dan `DB_PASSWORD`) ke dalam file pelacakan Git (seperti README atau `.env.example`).* `SESSION_SECURE_COOKIE` disetel `false` khusus operasi HTTP lokal, namun wajib dijadikan `true` apabila disebarkan ke jaringan HTTPS _Production_.
